Este é um projeto Java, onde estou praticando o que aprendi sobre POO nos últimos dias.

A função dele é bem simples, o desafio é criar um programa que implemente uma ContaBancaria segura.

O programa deve conter:

1) Atributos privados:

    * numeroConta;
    * titular;
    * saldo.

2) Construtor:

    * Deve inicializar a conta com o nome, número e um saldo inicial obrigatório.

3) Métodos:

    * Criar métodos para realizar ações solicitad pelo usuário.
